# Local verification contract

Current baseline: `npm run lint` in `frontend/` passed at `453c208`. The legacy Python unittest command failed at import because `cryptography` was absent. Docker service access and WebAssembly compilation were unavailable in the observed sandbox. These are not passed backend checks.

Planned repository entrypoints are `verify-fast`, `verify-integration`, `verify-security`, `verify-full`, `verify-fuzz`, `verify-performance`, and `rehearse-release`. An entrypoint will be documented as runnable only when its actual script exists and returns nonzero on a mandatory failure. Skipped mandatory checks must be recorded as `BLOCKED_TOOLING`, never PASS.

For the independent Python reference, the runnable command is `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests/reference -p 'test_*.py' -v`. It uses only the Python standard library. The fixed parity manifest in `tests/reference/corpus/manifest.json` has 33 literal expected operations across ten synthetic case fixtures and is exercised by `test_corpus.py`. The current full reference suite has 139 tests. A separate 200-seed synthetic receipt/checker run passed after M2-7c. This corpus covers a slice of the 48 RC scenarios; see `release-corpus.md`. The native core has local differential evidence below; WASM, identity, PostgreSQL, browser, concurrency, and recovery gates are pending implementation.

The first native slice has `make -C engine test-money` (Apple clang C++20; exit 0) and a local address/undefined sanitizer compile/run (exit 0). These checks cover exact cent parsing and checked arithmetic only.

The bounded JSON boundary also has `make -C engine test-json` and a local address/undefined sanitizer compile/run (both exit 0). It rejects duplicate keys, malformed UTF-8, inputs over 20 MiB, and nesting beyond 64; it does not yet validate Scryer case fields. The vendored `nlohmann/json` v3.12.0 header checksum matched the published SHA-256. Build and tests read the vendored header locally, with no build-time network fetch.

The strict native case parser has `make -C engine test-case case-probe` (exit 0), 200 seeded raw-case differential validations plus malformed variants against Python (exit 0), and an address/undefined sanitizer build and run (exit 0). The ten fixed synthetic cases parse successfully. The full Python reference suite has 139 passing tests. These checks cover validation and causal snapshots; the production CLI remains open.

Native school-surplus projection has `make -C engine test-projection projection-probe` (exit 0), address/undefined sanitizer compile/run (exit 0), all 13 fixed project/compare/history manifest operations, and 200 generated cases across 1,000 project/compare/history operations matching the independent Python reference. A reference regression test enforces checked signed-64-bit intermediate subtotals.

Native receipts have `make -C engine test-receipt receipt-probe` (exit 0), SHA-256 empty-input and `abc` standard vectors, address/undefined sanitizer compile/run (exit 0), all four fixed receipt digest expectations, 200 seeded synthetic receipts, two provenance-link variants, and historical reproduction/reanalysis tests. Full native receipt objects match the Python reference in compatibility mode, and the independent Python checker accepts each native output. The production native producer label is `native-0.1.0`; reference labels are exercised only for differential compatibility.

Native coverage, matching, and lifecycle have `make -C engine test-coverage test-matching test-lifecycle evidence-probe` (exit 0), separate address/undefined sanitizer compile/runs for all three native tests (exit 0), 15 fixed literal manifest operations, and 200 seeded synthetic cases across 1,000 coverage/matching/lifecycle operations matching the Python reference. Tests include source period retraction, split and overallocated deposits, account-specific matching, recipient mismatch/unknown/reviewed exception, annual aid, work-study, gross/fee/net, missing-fee evidence, and competing corrections. The production CLI and WASM/browser boundary remain open.

Full targets from the brief: 200 seeded cases for fast differential, 10,000 for full, 30 seconds per available fuzz target for smoke and 10 minutes for milestone, domain/reference 90% line and 85% branch coverage, sync/client 85% line and 80% branch coverage. These are requirements, not observed results. Every run records source revision, command, exit status, executed count, skips, and environment.
