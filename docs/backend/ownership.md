# Engineering ownership

Codex AI assistance is being used for design, code, tests, review notes, and local commits. This is not evidence that a human wrote each line or independently reviewed the result. Human review and independent security review: **not completed**.

For each subsystem, the lead developer should be able to explain its purpose, rejected alternatives, key invariant, most likely failure, and the test that catches that failure, then reproduce one change independently. The first exercise is to hand-compute the USD 1,500 → USD 900 correction scenario and explain why an observed bank credit cannot prove a school refund was owed.

Before a public product claim, obtain real format evidence, consented user-value research, qualified privacy/legal review, independent security review, funded operations, and human review of the actual release revision. None is represented as completed by a local automated run.
